AniList Quick Finish: Privacy Policy

Effective October 30, 2026. Covers AniList Quick Finish BETA 1.0.3. Independent extension; not affiliated with or endorsed by AniList.

Purpose and data

The extension adds remaining-watch-time rankings above the Watching section of an AniList anime list. On supported list pages, it reads the profile username from the page URL and locates the Watching heading. It queries the public AniList API for that username's Watching entries, including episode progress, anime titles/IDs, episode counts, durations, cover URLs, and airing information. It calculates remaining time locally. No sign-in, authentication tokens, cookies, private lists, account edits, automatic follows, or messages are used.

Local storage and retention

Public list responses are cached in extension service-worker memory for one minute and disappear when that worker is stopped. Diagnostic logs are saved in this browser's local extension storage, capped at the latest 150 events. Logs can contain the requested username, request timestamps, entry counts, media IDs, and API error text. The extension does not collect general browsing history, unrelated page content, or analytics. Logs are not synced by the extension. Clear logs through the extension icon popup; uninstalling deletes its local extension storage. Copying logs to the clipboard lets you choose where to share them.

Network requests and sharing

Read-only GraphQL queries are sent over HTTPS to graphql.anilist.co without cookies. AniList receives the queried username or media ID and normal request metadata, such as your IP address and request time. Covers load from the HTTPS image URLs supplied by AniList. Anime links navigate to AniList under your browser's ordinary session. No logs or list data are sent to the publisher or any analytics, advertising, or payment provider. There are no ads, payments, publisher-operated servers, or remotely loaded executable code.

Permissions and controls

Access to AniList pages lets the content script locate the Watching section and render the card. Access to graphql.anilist.co enables public-data requests. Storage is used for local diagnostic logs. Refresh fetches updated data; Show more expands the card in place. To stop page integration, disable the extension or revoke its AniList site access. The extension does not poll the API continuously.

Limited use and changes

Data is used only for the disclosed list ranking, catch-up estimates, display, and diagnostic features, consistent with the Chrome Web Store User Data Policy and Limited Use requirements. Data is not sold or used for advertising, creditworthiness, or lending. Material changes to data practices will be disclosed with an updated policy.
